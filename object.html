Where It Started

ANALOG
VS. DIGITAL.

Before we built anything, we started with the basics: analog vs. digital. Analog signals are continuous, like a dial turning or a light sensor slowly changing value. Digital is either on or off, HIGH or LOW, nothing in between.

Sounds obvious, but it's the foundation for everything below it. Every object here is either reading a continuous value (like pressure) or reacting to a single digital event (like a button press).

Fabrication

ENCLOSURES.

My first real enclosure was a basic light and button circuit built into a Labubu-shaped case. I modeled it from scratch in Rhino3D, printed it, and finished it by hand — hot glue gun to clean up the seams and hold the internal wiring down, and a magnet embedded in the case so it snaps shut instead of using a clip or screws.

Small object, but this is basically the workflow I stuck with for the rest of the semester: model it, print it, wire it, then finish it by hand until it actually looks done.

IDC 1

TYMB
Take Your Meds.

Arduino · Sensors · 3D design

TYMB stands for Take Your Meds, Bitch. I have ADHD, so remembering to take my meds is genuinely hard — before this, I'd get anxious about forgetting and end up counting all my pills by hand almost every day just to check. TYMB does that counting for me now.

Click to unmute

Tools
Arduino · Force Sensor · RTC · LCD
Type
Interactive Object
Trigger
Pressure Input

There's a pressure sensor built into a finger slot on the case. Press it to pull out a dose and it logs that against a real-time clock. An LCD screen shows what's been taken, what's next, and how many pills you've got left.

The pill tray and the lid both come off separately, so refilling doesn't mean taking the whole thing apart. There are seven slots total, one for each day of the week.

Future Work I want to switch the navigation over to a physical button, and pair the pressure sensor with stepper motors so the case can actually dispense a pill on its own instead of just logging that one was taken.

Solid Red — RefillThe case is running low, and the screen switches to a standing refill reminder until it's restocked.

IDC 2

MIRROROS.

MirrorOS is a smart mirror app, plus a physical remote that controls it so I never have to touch my phone. I wanted the interface to feel like Apple software — clean, glassy panels, no clutter. I built it in Electron and used Claude to help write a lot of the code.

The mirror itself is a discontinued Lululemon smart mirror, which already came with speakers, a camera, and a mic built in, so I figured I'd build on top of that instead of starting from a blank panel. There's an ultrasonic sensor behind the glass that checks if someone's actually standing in front of it, and dims, lights up, or turns the display off based on that.

I built a remote to control it instead of relying on touch. It's got a joystick — every direction moves you through the app, pressing down selects — plus back, home, and voice buttons. There's an ESP32 inside, which is what gives it Bluetooth and Wi-Fi. It talks to the mirror over Wi-Fi, but I set it up to run off a phone hotspot too, so it's not locked to one router.

  • VoiceHold it down and it triggers an AI agent (powered by Groq) that can navigate the app for you — "mirror, open Spotify," "mirror, open Pinterest."
  • JoystickMoves through every page. Press down to select.
  • Back / HomeGets you out of whatever page you're on.
  • ESP32Bluetooth and Wi-Fi, can run off a phone hotspot to stay portable.
